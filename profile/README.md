# 🎓 Marco Picone Teaching

This organization collects the teaching material used across lectures, university courses, and training activities: theory, playgrounds, and laboratories.
Each course or activity selects the modules it needs, so that all of them share the same, always up-to-date material.

- 📚 **Theory**: [mp-lectures](https://github.com/Marco-Picone-Teaching/mp-lectures), the single source of truth for all the lectures, organized by macro-topic
- 🛠️ **Source Code**: playgrounds and laboratories associated with the lectures
